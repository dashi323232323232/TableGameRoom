# TableGameRoom · TABLE 虚拟美元游戏厅

.NET 8 + WPF 桌面程序，完全离线、无数据库、无网络，所有筹码均为虚拟筹码。

## 构建与发布

```bash
cd D:\dsh\xin
dotnet build TableGameRoom.csproj -c Release
dotnet publish TableGameRoom.csproj -c Release -r win-x64 --self-contained true -o publish
```

输出：`D:\dsh\xin\publish\TableGameRoom.exe`（桌面快捷方式 `TABLE 游戏厅.lnk` 指向该目录，工作目录同为 publish）。

## 人机难度与思考时间

- 七档强度与下注档位**一一对应且完全平滑**：第 1 档 = 强度 1，第 7 档 = 强度 7，中间无任何断档跳变。所有 AI 参数（模拟次数、计算误差、抗压、诈唬、风险容忍、决策阈值）均由 `AiTuning` 按档位线性/二次插值生成。
- 各档强度对照：

| 档位 | 强度 | 蒙特卡洛次数 | 计算误差 | 抗压 | 诈唬 |
| --- | --- | --- | --- | --- | --- |
| 休闲 | 0.00 | 40 | 0.200 | 0.22 | 0.100 |
| 轻松 | 0.17 | 83 | 0.167 | 0.35 | 0.087 |
| 入门 | 0.33 | 213 | 0.133 | 0.48 | 0.073 |
| 普通 | 0.50 | 430 | 0.100 | 0.61 | 0.060 |
| 进阶 | 0.67 | 733 | 0.067 | 0.74 | 0.047 |
| 强手 | 0.83 | 1123 | 0.033 | 0.87 | 0.033 |
| 极强 | 1.00 | 1600 | 0.000 | 1.00 | 0.020 |

- 决策方式也是连续过渡：低档用查表/启发式，高档用真实胜率/贝叶斯推断，中间按强度百分比混合（如第 4 档各占 50%）。
- 电脑行动前会有随机「思考」停顿：前期小注约 0.5–1 秒（几乎秒出），后期大注可达 5–20 秒；**玩家自己的操作永远即时响应，不等待**。

## 任务系统

- 入口：模式选择页「任务中心」，以及任意页面顶部的「🎯 任务」按钮。
- 8 类任务：玩指定游戏 N 局、赢 N 局、用指定游戏赢 N 局、接受 N 次失利、累计净赢/净输、无限模式玩 N 局、单局净赢达标。
- 同时最多进行 3 个任务；完成即时发放虚拟奖金（金额低于任务目标，避免"做任务比赌博划算"）。
- 余额不足以最低档下注时，会引导前往任务中心——这就是破产保护。
- 任务按模式独立存于 `tasks.json` / `custom-tasks.json`。

## 模式、存档与历史

- 普通模式：`%LOCALAPPDATA%\TableGameRoom\progress.json`，余额默认 $1,000。
- 无限模式：`%LOCALAPPDATA%\TableGameRoom\custom-progress.json`，余额显示为 ∞，进度独立且不影响普通模式。
- 主存档字段：余额、局数、桌人数（2–7）、当前档位；损坏时回落到默认值。历史不写入主存档。
- 历史在玩法大厅右侧日历显示；按模式分别写入 `progress-history.json` 或 `custom-progress-history.json`，保留最近 3 个日历月的全部记录，不限条数。

## 下注规则

七档：休闲 $10–$500、轻松 $50–$1,000、入门 $100–$5,000、普通 $500–$10,000、进阶 $1,000–$50,000、强手 $5,000–$100,000、极强 $10,000 起（无上限）。

- 单次下注上限 = 当前档位上限（极强档无上限）。
- 牌局累计下注上限 = 单次上限 × 25 × 10（即档位上限的 250 倍）。
- 普通模式下注不得超过余额；无限模式无限筹码但仍受档位上限约束。
- 快捷下注按钮（$10/$20/$50/$100 等）按当前档位动态生成。

## 局域网联机

- 入口：模式选择页「🌐 局域网联机」。会话主机点「创建房间」生成端口号，其他人用「加入房间」填端口号连入（UDP 广播 47899 可自动发现同网段主机）。
- 联机游戏：21 点、德州扑克、炸金花、骗子扑克（**联机轮盘已移除**）。
- 房间内房主可：选游戏、设档位 / 倒计时、勾选谁参战、设定本局总人数、点玩家头像改其筹码（任意金额或 ∞）。
- **参战勾选 + 总人数 + AI 自动补位**：勾 3 个真人选 3 → 3 真人；选 5 → 3 真人 + 2 AI，按钮上直接标注「5（+2AI）」。
- 联机测试：`tools/verify-lan*.ps1`（9 个脚本，共 75 项，全部通过）。
- 详细需求与实现记录见 `局域网联机需求.md`。
